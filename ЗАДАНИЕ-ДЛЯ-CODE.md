# Задание: фото в тему san-zori и архив для WordPress

Тема сайта san-zori.ru собрана в чате. Твоя часть — подложить в неё фото из `media/renamed/`, собрать архив для загрузки и прочитать данные лицензии. PHP, CSS и тексты темы не меняй: все правки идут через чат, чтобы версия была одна.

## Что в комплекте

- `san-zori/` — тема WordPress без фото (без фото она тоже работает: вместо снимков цветные блоки)
- `img-map.csv` — какой файл из `media/renamed/` идёт в какой блок сайта
- `add_photos.py` — кладёт фото в `san-zori/assets/img/`, ужимает их и собирает `san-zori.zip`

## Шаги

1. Распакуй комплект в корень `kasimov-zori/`, рядом с папкой `media/`.
2. Установи Pillow, если его нет: `pip install pillow`.
3. Запусти: `python add_photos.py --media media/renamed --theme san-zori --out san-zori.zip`
4. Если скрипт написал «не найдено» — подбери замену из той же папки `media/renamed/<раздел>/` по листам-превью, исправь строку в `img-map.csv` и запусти снова. Людей крупным планом не бери: санаторий просил не публиковать фото людей.
5. Проверь архив: внутри одна папка `san-zori/`, в ней `style.css` и `assets/img/*.jpg`. Размер — до 8 МБ.
6. Открой скан `media/renamed/dokumenty/dokumenty-01.jpg` (лицензия) и выпиши номер лицензии, дату и кто выдал. Если плохо читается — посмотри `dokumenty-02.jpg`…`04.jpg`.

## Обновления темы

Когда из чата приходит новая версия комплекта, распакуй её поверх `kasimov-zori/` с заменой файлов и снова выполни шаги 3 и 5. Фото вернутся в тему из `media/renamed/`, и получится новый `san-zori.zip`. Данные лицензии повторно выписывать не нужно.

## Отчёт

Коротко: сколько фото легло, что заменил и почему, размер архива, номер и дата лицензии. Путь к `san-zori.zip` — пользователь загрузит его в WordPress (Внешний вид → Темы → Добавить → Загрузить тему).

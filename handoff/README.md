# Пакет для чата — «Касимовские Зори» (этап 5)

Сайт санатория «Касимовские Зори» переносится со старого статичного сайта (kasimovskie-zori.ru) на WordPress с новой структурой блоков (прототип). В пакете — всё, что вытащено со старого сайта дословно, плюс карта «старое → новое», модель данных и список вопросов к руководству.

**Ваша задача в чате:** переписать тексты под блоки прототипа и подготовить документ на согласование. В этом пакете тексты не переписаны и не сокращены. Где на старом сайте пусто — стоит `[НЕТ НА СТАРОМ САЙТЕ]`; цены, ФИО, названия и цифры не додумывать — для них есть вопросы в `questions.md`.

Собрано 2026-11-11. В карте 339 строк, в редиректах 252, листов-превью 44.

## Что где лежит

| файл / папка | что это |
|---|---|
| `content-map.csv` | **главный файл**: каждая секция старых страниц → новая страница → блок прототипа → тип → статус |
| `content/old/*.md` | тексты старых страниц, по файлу на страницу; `_common.md` — шапка, меню, подвал; `_js-data.md` — то, чего не видно на странице без клика (цены всех периодов, цены процедур и коттеджей, акции, отзывы) |
| `questions.md` | вопросы к руководству: A — блоки прототипа без контента, B — открытые вопросы этапов 1–3, C — новые |
| `content-model.md` | предложение по типам записей, таксономиям и полям (в духе ACF) под блоки прототипа |
| `redirects.csv` | старый адрес → новый (301), якоря, 7 битых страниц |
| `facts.csv` | цены, телефоны, e-mail, адреса, часы, цифры с единицами (тип, секция, значение, страница, якорь) |
| `images.csv` | все 1384 ссылки на картинки: размеры, вес, флаги, дубли, где используются |
| `vip-room-photos.csv` | фото 18 номеров VIP-корпуса (в `corpus2-room*.md` их нет) |
| `media/sheets/*.jpg` | листы-превью по разделам: сетка миниатюр с именем файла, размером, весом |

## Как читать

**content-map.csv.** Колонки: `old_url` (с `#якорем`), `old_section`, `new_url`, `new_slug`, `proto_block` (блок прототипа), `type`, `status`, `words`, `photos`, `photos_low_res`, `photo_files`, `note`.
- `type`: страница, процедура, программа, проживание, акция, FAQ, документ + добавлены новость, отзыв и служебное (не переносится).
- `status`: `текст есть` / `текста нет` (меньше 8 слов или только таблица цен — тогда в `note` «только прайс») плюс `мало фото` (1–2 фото) или `нет фото` (0), если для этого типа фото нужны. Фото меньше порога 3 — `мало фото`; для новостей порог 1. `не переносится`, `контейнер`, `в настройки темы` — служебные значения.
- `new_url` — предложение, не утверждено. `—` — переносить не нужно.
- Строки без текста с блоком «Главная · N …» — это и есть ответ на вопрос «что на старом сайте есть для этого блока».

**content/old/*.md.** В шапке: `old_url`, `title`, `meta_description`, `h1`. Дальше секции `## Заголовок {#якорь}`, подсекции `###`. Под каждой секцией — список картинок: `- new: <раздел>/<файл> | src: <старый URL> | alt: "" | via: …`. `new:` — имя файла в `media/renamed/` (самих файлов в пакете нет, смотрите на листах). Таблицы — markdown-таблицы.

**Фото.**
- Лист `media/sheets/<раздел>.jpg` (большие разделы — `-p01`, `-p02`…): под миниатюрой имя файла, размер, `low_res` (длинная сторона меньше 1200 px), `×N` (сколько файлов склеено как дубли).
- На старом сайте **нет alt ни у одной картинки** — alt пишется заново.
- 65% фото меньше 1200 px (почти все фото новостей, коттеджей, медкабинетов). Оригиналов покрупнее пока нет.
- **Ловушка «зигзаг».** На страницах `programms_treatment`, `programms_meduslugi`, `programms_izuminki`, `programms_equipment` картинки в вёрстке то слева, то справа от текста, поэтому в `.md` они прицеплены к соседней секции. Реальное соответствие — k-я картинка страницы = k-я процедура/программа/аппарат; оно записано в колонке `photo_files` карты (одно фото на элемент). Проверено глазами по листу `spa.jpg`: `spa-01` — соляная пещера; снимок лазера на руке — ВЛОК, а не пещера.
- Для новостей `photo_files` — фото конкретной новости (превью `…-mini` включено).

**redirects.csv.** `kind`: страница (301), битая страница, файл, якорь. Якорь серверный 301 не видит (фрагмент до сервера не доходит) — строки `якорь` нужны для JS-перехода или справочно. Пара якорей на старой странице повторяется (`#cosmetology`, `#programideal` в izuminki) — в таких строках стоит пометка.

**facts.csv.** Колонки: тип, секция, что (контекст), значение, страница, якорь, slug. Цифры и цены из федеральных актов в `documents.md` (`#doczaschitaprav`, `#docfreemedicine`) не выписывались.

## На что обратить внимание

- Цифры расходятся: 14 / 12 / 8 программ, «450 номеров» и «450 мест в 5 корпусах», коттедж №1 — 420 и 355 кв.м, адрес «с. Телебукино» и «д. Телебукино, д. 7Е». Не выбирать за руководство — выносить в вопросы.
- Дубли текста: косметология (два разных варианта), озонотерапия (идентична), «Коттеджи расположены…» на страницах корпусов 1, 2 и коттеджей; 4 новости опубликованы на двух страницах-годах.
- Прайсы датированы: процедуры «с 01.02.2026», доп. услуги «01.02–30.12.2026», новогодние — период 31.12.2025–11.01.2026 уже прошёл.
- Якорь `#lechebnodiagmanipul` на старом сайте закомментирован; секции «Лечебно-диагностические манипуляции» нет якоря.
- Блоки прототипа без контента перечислены в `questions.md`, раздел A (СПА-бани, спорт, боулинг, прокат, мероприятия, территория, врачи, «как проходит лечение», показания по процедурам, SEO-тексты).
- Прототип, образец dobrograd-hotel.ru, `about.docx` и сами файлы фото в пакет не входят; структура блоков прототипа — в `content-map.csv` (колонка `proto_block`) и `content-model.md`.
